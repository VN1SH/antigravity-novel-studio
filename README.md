# Novel Studio —— Antigravity 多 Agent 长篇小说创作工坊

一个基于 **Antigravity Swarm** 的开源长篇小说多 Agent 协同创作插件框架。

本插件只提供**通用协同架构、记忆管理机制与审校流转闭环**：
- **模型完全自由选择**：不绑定任何固定模型，开书或写作时可为每个角色自由指定任意可用模型（支持异构模型混搭）。
- **文风与审查标准完全自定义**：内置的 `codex/style_guide.md`（个人文风规范）与 `codex/review_criteria.md`（个人审查标准）均为空白模板，由你按自己的偏好和提示词自由填写。

---

## 核心特性

1. **四角色协同 + 主编全流程把关制**
   - **执行主编 / 编剧（`coordinator`，主代理）**：原则上不代写整章正文，负责立项讨论、大纲与分章细纲、全流程六道审核闸门（章前简报复核、细纲制定、初稿骨架一审、审查意见采纳/驳回裁决、正文终审定稿、归档终验）并掌握唯一最终定稿权。
   - **写手（`writer`）**：仅负责按定版细纲与你的 `codex/style_guide.md` 执笔正文和定向精修，不越权修改设定库。
   - **自定义审查官（`reviewer`，可选）**：完全只读，严格按你填写的 `codex/review_criteria.md` 与 `codex/style_guide.md` 输出带编号修改建议，由主编逐条裁决（✅ 采纳 / ❌ 驳回）后再交写手精修。
   - **客观档案员（`archivist`）**：绝对中立客观，不参与创作，负责维护酒馆式世界书、每章摘要、时间线、人物动态与伏笔/暗线台账，章前提醒填坑、章后查吃书并沉淀入库。
2. **酒馆式世界书（Lorebook）**
   - 汇总正文与大纲设定，采用 **`[常驻核心]` + `关键词触发索引表` + 分类词条** 结构；
   - 严格区分 **`[正文已确立]`** 与 **`[仅大纲·未公开]`**，防止写手提前剧透或角色凭空知晓未公开设定；
   - 档案员在章前充当活体“关键词触发引擎”，按本章涉及关键词精准捞取对应词条；超大篇幅支持自动按分类拆册。
3. **长篇滑动窗口阅读协议**
   - 写几十万字也不爆上下文：开写第 N 章时，**主编读最近 10–15 章全文**、**写手读最近 5–10 章全文**，更早剧情统一通过 `codex/chapter_summaries.md`（每章摘要 + 卷级折叠总览）与酒馆世界书按需衔接。
4. **强制人工确认门禁（Hard Stop）**
   - 每章细纲出炉后强制暂停，必须等你确认或提出修改意见后才会通知写手开写正文。

## 安装方式

将本仓库克隆到 Antigravity 的全局插件目录（`~/.gemini/config/plugins/novel-studio`）：

### Windows (PowerShell)
```powershell
git clone https://github.com/VN1SH/antigravity-novel-studio.git "$env:USERPROFILE\.gemini\config\plugins\novel-studio"
```

### macOS / Linux
```bash
git clone https://github.com/VN1SH/antigravity-novel-studio.git ~/.gemini/config/plugins/novel-studio
```

安装完成后，插件会在 Antigravity 中自动发现并加载（你也可以在左侧边栏 **Skills & Customizations** 中随时查看或一键开关）。

## 快速上手

1. **选择主代理模型**：在 Antigravity 对话中切换你希望担任「主编 / 编剧」的模型。
2. **开书立项**：发送提示词：
   > 「我要开一本新小说，先帮我配置各角色模型并聊聊题材和大纲，再搭建项目与酒馆式世界书」
   - 主代理会先查询当前可用模型列表，让你自由为 `writer`、`reviewer`、`archivist` 指定各自模型，并记录到项目的 `NOVEL_STATUS.md` 中。
3. **填入你的个人文风与审查标准**：
   - 编辑项目中的 `codex/style_guide.md`：写入你自己的文风规范、写作偏好或参考样段；
   - （可选）编辑项目中的 `codex/review_criteria.md`：写入你自己的文本质检标准、禁用词或审校清单，供 `reviewer` 执行审查（若留空，可在创作时跳过或仅由主编把关）。
4. **逐章创作**：直接说「开始写第 X 章」，自动按七阶段闭环推进：
   ```text
   1. 档案员章前触发简报（关键词捞取世界书词条 + 人物信息差 + 待填伏笔/暗线）
           ↓ [主编闸门 1：复核简报]
   2. 主编按滑动窗口拟定本章细纲 ──→ 【强制暂停，等你确认】
           ↓ [主编闸门 2：确认细纲并下发轻量化写作简报]
   3. 写手按细纲与你的 style_guide.md 执笔初稿
           ↓ [主编闸门 3：初稿骨架一审（逻辑/因果/OOC/防剧透）]
   4. （如启用）审查官按你的 review_criteria.md 输出编号建议
           ↓ [主编闸门 4：逐条裁决 ✅采纳 / ❌驳回 → 写手定向精修]
   5. [主编闸门 5：终审通读并签发定稿令（唯一最终定稿人）]
           ↓
   6. 档案员查吃书并完成五大沉淀（章摘要 / 时间线 / 伏笔暗线 / 世界书 / 人物动态）
           ↓ [主编闸门 6：复核入库成果并向你交付]
   ```
5. **全书审计与存量建档**：随时说「对目前已写章节做全书审计：查吃书、补全每章总结与世界书、盘点伏笔暗线」。

## 标准小说项目目录结构

```text
<novel-project>/
├── NOVEL_STATUS.md                # 团队模型配置、章节进度与状态总览
├── outline/
│   ├── master_outline.md          # 总纲、分卷规划与核心暗线
│   └── chapter_outlines/          # 每章确认后的细纲存档
│       └── ch001.md
├── chapters/                      # 正文章节
│   └── ch001.md
└── codex/                         # 设定与记忆库
    ├── style_guide.md             # 【用户自定义】个人文风规范与写作偏好
    ├── review_criteria.md         # 【用户自定义】审查官质检标准（留空则跳过或按需启用）
    ├── worldbook.md               # 【档案员维护】酒馆式世界书（[常驻核心] + 关键词触发索引 + 词条）
    ├── chapter_summaries.md       # 【档案员维护】每章摘要与暗线总录（含卷级折叠总览）
    ├── characters.md              # 【档案员维护】人物动态档案与信息差
    ├── timeline.md                # 【档案员维护】时间线与大事记
    └── foreshadowing.md           # 【档案员维护】长期暗线（Sxxx）与具体伏笔（Fxxx）台账
```

## 内置 Skills

- `novel-init`：开书立项、角色模型配置、大纲头脑风暴与目录/世界书初始化
- `novel-chapter`：单章多角色协同创作闭环（含主编六道闸门、滑动窗口与细纲确认门禁）
- `novel-audit`：全书逻辑查吃书、伏笔暗线盘点、存量小说一键补建每章总结与酒馆世界书、按用户标准执行专项审校
